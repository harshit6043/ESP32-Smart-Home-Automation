# ESP32 Smart Home Automation Using Blynk IoT

## Project Overview
This project aims to control eight electrical appliances using an ESP32 microcontroller, Wi-Fi connectivity, and the Blynk IoT mobile application.

## Components Required
- ESP32 DevKit
- 8-channel relay module
- Connecting wires
- Suitable power supply
- Blynk IoT application
- Test loads

## Features
- Eight-channel appliance control
- Smartphone-based ON/OFF switching
- Wi-Fi connectivity
- ESP32-based embedded control
- Blynk virtual-pin integration

## Technologies Used
- Embedded C++ / Arduino
- ESP32
- Blynk IoT
- Wi-Fi
- Relay interfacing

## Project Status
In development. Hardware testing and validation are pending until completed.

## Safety
Mains-powered loads require appropriate electrical isolation, rated components, and qualified installation.
